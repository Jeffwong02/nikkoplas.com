# 360° factory photos

Drop equirectangular panoramas (2:1 ratio, e.g. 6000x3000 JPG, under ~4 MB each) here, then
list them in `scenes` inside `/factory-360/index.html`. Shoot with a 360 camera or a phone
panorama app (Google Street View app, Insta360, Ricoh Theta). Name files like `entrance.jpg`.
